# KWA FEE Artifact 4 — Machines & Sabotage (spec)

> Beads id `kwaffee-kvu` | Slug `04-machines-sabotage`. This is the durable spec for the artifact; the grill memo `.scratch/kwafee/grilling/04-machines-sabotage.md` is the source of every decision recorded here.

## Problem Statement

From the player's perspective: the four machines (Espresso, Grinder, Steam Wand, Ice Machine) are scene objects with a single health float — they degrade, break, and get wrenched, but there is no moment ever worth replaying. Sabotage is a generic health nudge: it makes a machine slower, not funny. There is no geyser, no steam scald, no chain of machines dying one after another, no reason to watch a replay of the shift. When I sabotage a machine, nothing visibly terrible and hilarious happens to whoever uses it next. When my friend wrenches a broken machine, repair is a chore with no tension. Machines need docs because nothing about them is readable from sight.

## Solution

From the player's perspective: every machine now has a second, visible life — overpressure. Sabotage a machine and it starts shaking, bulging, and wisping steam; use it while it is PRIMED and it blows up in your face: a geyser of ≥12 physical beans, a steam burst, camera shake, hitstop, and a stun. The Steam Wand scalds anyone in range on its next use. A wrench vents a PRIMED machine with a hiss (defusing the prank — a sprint, not a guarantee) and revives a broken one. When one machine blows, the spray nudges its neighbors, so a shift can cascade: two or more machine events inside 6 seconds, one after another, the kind of moment the CATASTROPHE REPLAY exists for. Every one of these moments is emitted as a deterministic, seeded event — the same seeded shift always re-simulates to the same events, which is exactly what Artifact 8's replay needs. The game tells you all of this without a single line of instructions: health shows as a worn tint and wobble, PRIMED machines shake and bulge, and Big Vinny drops exactly one nudge the first time a machine gets primed or breaks.

## User Stories

1. As a saboteur, I want SABOTAGE on a machine to raise its overpressure, so that I can prime a trap for the next person who uses it.
2. As a saboteur, I want to see a machine cross into PRIMED (shake, steam wisps, squash-stretch bulge) the moment overpressure hits 1.0, so that I know my trap is armed.
3. As a victim, I want using a PRIMED machine to fire a geyser of ≥12 physical beans in my face, so that the prank is comically on me, not on the saboteur.
4. As a victim of the Steam Wand, I want swinging a PRIMED Steam Wand to emit a scald burst that stuns anyone in range with an "OW", so that the wand reads as both weapon and tool.
5. As a machine, I want health to drive a 4-rung ladder — HEALTHY, WORN, JAMMED/BROKEN — so that my degradation is readable at a glance.
6. As a victim, I want the geyser to include camera shake, hitstop, and a stun, so that being buried in beans is a replay moment, not a stat change.
7. As a friend, I want FIX on a PRIMED machine to vent overpressure to zero with a hiss and a relief puff, so that I can defuse a sabotage trap mid-shift.
8. As a friend, I want FIX on a BROKEN machine to revive it, so that the wrench stays a real repair tool, not just a defuser.
9. As a player, I want to be able to defuse a trap while the cascade is already running, so that sabotage turns into a sprint instead of a guaranteed hit and stays funny, never rageful.
10. As a player, I want a geyser's flying beans and a scald to shave a little health off adjacent machines, so that one machine event can ripple into the next.
11. As a player, I want ≥2 machine events inside a 6-second window to count as a cascade, so that chain-failures are recognized as the shift's best moment.
12. As a player, I want every geyser to be replay-worthy by construction (beans + stun + shake), so that a single event can carry the CATASTROPHE REPLAY.
13. As a player, I want each machine's geyser payload to match its identity — coffee beans, grounds, sad ice cubes, steam only — so that the blast is per-machine, not a re-skinned copy.
14. As Artifact 8 (replay), I want a timestamped, pooled, capped `MachineEvent` log of geyser/scald/breakdown/fix/prime transitions, so that I can re-simulate a captured seeded window without Artifact 4 building any playback.
15. As a player, I want the whole machine system to run on the seeded per-shift RNG with no wall-clock reads, so that the same seed always produces the same shift.
16. As a player, I want to read machine state from sight alone — grubby tint and wobble when worn, shaking and wisping when primed — so that nobody needs docs.
17. As the /sim harness, I want to run ≥40 seeded shifts across the four bots and get a per-shift cascade count, so that the ≥80% cascade gate is a boring numeric assertion.
18. As a machine, I want a PRIMED machine that breaks before it is used to simply jam, so that the geyser trigger is always a use and never a mystery timer.
19. As a player, I want a PRIMED intact machine that is never used to stay primed, so that the trap persists until someone triggers it — the prank stays the saboteur's.
20. As the BUILDER, I want the first prime and the first breakdown of a shift to fire exactly one Vinny nudge, so that the tutorial is one funny line instead of a screen.

## Implementation Decisions

- **`overPressure[4]` parallel to `machineHealth`.** One new float array, 0..1, shared across all four machines, kept orthogonal to health. A machine may be healthy AND primed, broken AND primed, or any other combination. Health answers "will it produce"; overpressure answers "will it blow on the next use." No per-machine subsystems (YAGNI; friendslop). Overpressure rises under SABOTAGE; the exact raise (memo: SABOTAGE was `-0.35` health; overpressure gain tuned by /sim, never intuition) is a balance value owned by Artifact 12, measured in this artifact's /sim report.
- **Derived states, no per-kind enums.** Health maps to a uniform 4-rung ladder: `HEALTHY (≥0.70)`, `WORN (0.35–0.70)`, `JAMMED/BROKEN (≤0.35 — no production; wrench revives)`. Overpressure maps to `SAFE (<1.0)` / `PRIMED (≥1.0)`. No per-machine enums; the visual and rule ladder are identical across machines, only the geyser payload differs. "Grinder jams — wrench" is the same BROKEN rung as everything else.
- **Geyser fires on the next USE of a PRIMED machine.** The saboteur primes; the next user — victim or anyone — triggers their own geyser by pulling from the machine. The victim is always the one buried: fun over fidelity. A PRIMED machine that breaks unused simply jams (no geyser); the trigger is a use, always. A primed, working machine that is never used stays primed.
- **Geyser = pooled Rigidbody bean burst + steam ParticleSystem + camera shake + hitstop + user stun.** ≥12 pooled Rigidbody beans (the bounce is the joke, so they are physical, reusing the existing physics-object pool discipline — zero per-frame allocation). Steam is a GPU ParticleSystem sprite, not a mesh. One geyser code path; per-machine payload prefab slot: Espresso = coffee beans, Grinder = grounds, Ice Machine = sad ice cubes, Steam Wand = steam only. Stun reuses the Artifact 3 stun/death/react path — no new stun system.
- **Steam scald uses the same prime-on-use pattern.** SABOTAGE on the Steam Wand primes it; the next swing/use emits a scald burst — steam ParticleSystem + AoE radius that stuns anyone in range ("OW") and deals a small health drain to adjacent machines (cascade seed). Uniform trigger: one rule to learn; scald is the weaponized reading of the same mechanic. This is the spec's machine "weapon + tool" split.
- **FIX vents, FIX revives, and repair is valid mid-cascade.** FIX on a PRIMED machine drops overpressure to 0 with a hiss and a small relief puff ("that was close" — Vinny line). FIX on a BROKEN machine revives it to production. Both remain valid while a cascade is running. This is the designed counterplay and the anti-grief rail: a victim/friend can wrench a shaking machine to defuse the prank, turning sabotage into a defuse sprint instead of a guaranteed hit, and keeps FIX relevant mid-shift (Artifact 2's gate: STEAL most-used, FIX must never be dead weight).
- **Cascade = ≥2 machine events within 6 seconds, seeded by zero-new-physics mechanisms.** Seed mechanisms: a geyser's flying beans deal a small health drain to adjacent machines on impact; a scald AoE drains adjacent-machine health; a geyser flings the victim into a neighbor; a broken machine stalls production, which piles pressure on the shop. The chain emerges from existing degradation plus the new AoE nudge — nothing new to build. A cascade event is one countable unit per 6s window (a geyser also counts as a machine event).
- **Pure seeded + event-driven determinism contract.** All machine logic is a pure function of `(state, inputs, dt, seededRng)`. No wall-clock, no `Time.unscaledTime`, no nondeterministic physics reads feeding state. Geysers/scalds/breakdowns are emitted as deterministic events from the sim step — they are data, not side effects. Seed = the per-shift seeded RNG CoreGame already owns. This single contract is what makes the Artifact 8 replay axis and the ≥80% gate possible.
- **`MachineEvent` log: the Artifact 8 contract, not the replay.** A pooled, capped, timestamped log of `(shiftTime, machineId, kind, fromState, toState)` for kinds `geyser | scald | breakdown | fix | prime`. Pooled and capped: bounded allocation, matching the pooled-physics discipline. Artifact 4 ships the log and the documented determinism guarantee (seeded pure function + fixed-tick step); it MUST NOT build playback, slow-mo, or recording UI — that is Artifact 8's job. The event log is the seam.
- **/sim gate proxy is numeric.** Proxy = cascade events per shift ≥ 1 in ≥80% of scripted seeded shifts, where a cascade = one geyser OR scald OR breakdown that triggers a second machine event within 6s (or any geyser alone — beans + stun + shake is replay-worthy by definition). /sim runs N≥40 seeded shifts across the 4 bots, reports `cascadesPerShift` and the ≥80% pass rate. Numbers gate first; RATER feel judgment second.
- **Self-teaching is ambient + one Vinny nudge, zero docs.** Degradation visible via code-driven worn tint lerp + wobble vibration; PRIMED machines visibly shake, squash-stretch bulge, and wisp steam; FIX/SABOTAGE proximity verb works on visible machines. First prime and first breakdown of a shift each fire exactly one Vinny nudge ("That steam wand looks wicked thirsty, kehd"). If a fresh player cannot read "shaking machine = about to blow, wrench defuses it" from sight, the gate fails.
- **External dependency — the Shift seam ticket is NOT this artifact's work.** This artifact's machine logic sits behind the shift-seam contract (`kwaffee-6id`, "shift-seam": all gameplay intent enters via `Shift.Command`, state exits via `Metrics()`, fixed-step lockstep, /sim drives the same `Step`). Artifact 4 consumes that seam: SABOTAGE/FIX enter as commands, machine state and the `MachineEvent` log exit as state/readout, determinism follows the seam's seeded fixed-tick invariant. Building or refactoring the seam itself is out of scope here; it is tracked by `kwaffee-6id` and the machine system must be authored so it plugs into the seam when it lands (pure rule modules, no rules in MonoBehaviours).

## Testing Decisions

- **Determinism is the load-bearing test.** For the same seed + fixed scripted policy, /sim must yield identical `cascadesPerShift`, identical `MachineEvent` sequences (same kinds, same shiftTimes, same order). This is the regression guard that keeps the Artifact 8 contract real; geysers as data is the exact property this test defends.
- **EditMode tests for the machine rule module** (pure-function style matching the existing machine-rule suites, which are the prior art): overpressure/health orthogonality (healthy+primed, broken+primed), the 4-rung health ladder boundaries (0.70, 0.35), PRIMED-at-1.0 cross, geyser-on-next-use (including "breaks unused → jams, no geyser"), FIX vents primed to 0 / revives broken / both valid mid-cascade, scald AoE stuns and drains adjacent health, cascade counting (≥2 events in 6s = one cascade; single orphan event = none).
- **Geyser surface tests assert what a consumer observes**: ≥12 beans spawned from the pooled burst, payload per machine kind, stun applied via the Artifact 3 path, steam ParticleSystem emitted, hitstop+shake requested. Do not assert internal wiring, pool internals, or constants.
- **Pool discipline test**: a scripted geyser-heavy window shows no new allocations per frame (pooled beans + capped event log) — the 60fps budget is a blocker-grade regression.
- **/sim gate test**: ≥40 seeded shifts across 4 bots; report `cascadesPerShift`; pass rate ≥80% with ≥1 cascade per shift. The numbers gate runs before any RATER judgment; cascade rate tuning happens against this report, never by intuition.
- **Sight-readability test**: a primed, a worn, a broken, and a healthy machine must be distinguishable in a headless screenshot pass by tint/wobble/bulge/steam — no text labels. First-prime and first-breakdown Vinny nudges are asserted as single firings per shift.
- Prior art: the existing machine-rule test suites (health threshold, `IsBroken`, FIX/SABOTAGE as health nudges) are the regression guard for the refactor; assertions that pinned the old "SABOTAGE is a health nudge" behavior move to the new overpressure semantics or are deleted, never re-pinned.

## Out of Scope

- **Bean-sack and trip-wire** — player/NPC-targeted griefing verbs, owned by Artifact 2 (five verbs + griefing). The four machines are the only sabotage surface in this artifact.
- **Replay playback, slow-mo, recording UI** — Artifact 8's job; Artifact 4 ships only the `MachineEvent` log + determinism guarantee.
- **The shift-seam refactor itself** (`kwaffee-6id`): external ticket; this artifact consumes its contract, does not build it.
- **No new physics systems** — the cascade is seeded by existing degradation + the AoE health nudge; no cross-machine coupling physics.
- **No per-machine state enums or bespoke subsystems.**
- **No machine geometry** — degradation is code tint + wobble; zero new mesh on the four rigs.
- **No tutorial text or docs.**
- **Balance tuning of rates/raises beyond what the /sim cascade gate needs** — cascade frequency, overpressure raise, scald range are measured here and finalized by Artifact 12.

## Refined Gate

Measurable definition of done for this artifact (from the memo's refined acceptance criteria, in the artifact's own language):

- All 4 machines expose the derived 4-rung health ladder (HEALTHY/WORN/JAMMED/BROKEN) driven by `machineHealth` and a parallel PRIMED/SAFE state driven by `overPressure[4]`; the two axes are orthogonal (healthy+primed, broken+primed both reachable).
- SABOTAGE raises overpressure; crossing ≥1.0 = PRIMED (visible shake + steam wisps + squash-stretch bulge). The next USE of a PRIMED machine fires a GEYSER; a primed machine that breaks unused jams without a geyser.
- GEYSER = ≥12 pooled Rigidbody beans (or grounds / sad ice / steam payload per machine) + steam ParticleSystem + camera shake + hitstop + user stun — replay-worthy by construction.
- Steam Wand SABOTAGE → PRIMED; the next swing scalds (steam + AoE stun "OW" + small adjacent-machine health drain).
- FIX vents PRIMED overpressure to 0 (hiss + relief puff) and revives BROKEN machines; both valid mid-cascade. This is the defuse counterplay.
- Cascade: a geyser/scald/breakdown nudges adjacent-machine health; ≥2 machine events within 6s = one cascade event. Any geyser alone counts as a replay-worthy moment.
- All RNG seeded; machine logic a pure function of `(state, inputs, dt, seededRng)`; zero wall-clock/nondeterministic state reads; same seed replays byte-identical events.
- `MachineEvent` log pooled + capped, timestamped `(shiftTime, machineId, kind, fromState, toState)` for geyser/scald/breakdown/fix/prime — the Artifact 8 contract. No playback built here.
- /sim: ≥40 seeded shifts across the 4 bots, reporting `cascadesPerShift`; pass rate ≥80% with ≥1 cascade per shift.
- Zero per-frame allocation (pooled beans + pooled event log); the 60fps 4-player budget holds.
- Self-teaching: first prime and first breakdown each fire exactly one Vinny nudge; no docs; machine states sight-readable (tint/wobble/bulge/steam).
- Blender art: any new visible mesh (geyser beans if no reusable bean, wrench, steam sprite) authored via the bpy pipeline, manifest-validated, ≤35,000-tri total cap, origins grounded y=0, per-submesh material indices.
